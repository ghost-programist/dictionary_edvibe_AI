# Тренажёр слов

Сайт на HTML, CSS и JavaScript. Слова и переводы записываются только вами и хранятся в файле `words.json`. Готовых примеров в приложении нет.

## Как пользоваться

1. Откройте `index.html` в браузере.
2. Нажмите **Открыть words.json** и выберите файл `words.json` из этой папки. После этого новые слова и отметки «выучено» будут писаться в этот файл.
3. Если браузер не умеет сохранять файл напрямую, нажмите **Сохранить файл** — скачается актуальный `words.json`.

Формат файла:

```json
[
  {
    "id": "1",
    "term": "слово",
    "translation": "перевод",
    "learned": false
  }
]
```
